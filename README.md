# 火试炼 · 网页版（单文件离线 3D）

> 一个可以直接双击打开的 3D 网页版「火试炼」关卡：**自动巡游 + 自由飞行**，**离线单文件**、无需服务器、无需联网。

两个文件都是**完全自包含**的：JS、几何、纹理全部内联在同一个 HTML 里，拷贝到任何电脑/手机双击即可打开。

> 手机打开：把 HTML 发到手机（微信/QQ/网盘均可），用手机浏览器打开；竖屏/横屏都支持，横屏体验更佳。

## 操作说明

**电脑**
- `W A S D` 移动、`Space / Ctrl` 上升下降、`Shift` 加速（×2）
- 鼠标拖拽环视；**右键锁定鼠标**（隐藏光标，FPS 手感，`Esc` 退出）
- `M` 或右上角按钮切换「自由移动 / 自动巡游」；`R` 回到起点
- 滚轮缩放视野

**手机**
- 左下**虚拟摇杆**移动；右下 `↑ / ↓` 升降；`2×` 按钮点击切换加速（再点关闭）
- 右半屏拖拽环视；右上角按钮切换模式

**URL 参数（可选）**
- `?poster=1` 静态封面（无 WebGL 环境兜底）
- `?debug=1` 显示 FPS / draw call / 三角形 / 分辨率
- `?dpr=1&quality=low` 进一步降低渲染负载

## 技术说明（简述）

- 从 UE4.25.4 关卡工程的 `.umap` / `.uasset` 中解析出：地形（9 个 Landscape / 711 个组件）、161 个静态网格实例、156 盏点光、14 个火球、12 个烛台。
- 地形高度图（512² 图集 + 128² 子块）与层权重还原成合并网格；**光照全部离线烘焙进顶点色**，运行时 **0 盏实时灯光**。
- 最终：**1 个地形网格 + 4 个实例合并网格 + 2 个火焰精灵批次 + 1 个天空球 = 8 个 draw call**，约 **16.8 万三角形**，单文件 **≈5 MB**。
- 关卡是**蓝白色灵火**的夜色试炼场：浮空岛屿地形、白模石柱/石墙、沿路烛火与大火球。

## 已知问题 / 兼容性

- **Debian/Ubuntu + Wayland + Edge**：部分环境下 Edge 的 GPU 进程会异常退出（表现为窗口闪退）。建议用下面参数打开（强制 XWayland 并关闭 Vulkan）：

  ```bash
  microsoft-edge-stable --ozone-platform=x11 --disable-features=Vulkan \
    --allow-file-access-from-files ./火试炼.html
  ```

  或直接使用低配版 `火试炼-低配.html`；也可在 `edge://flags` 里禁用 Vulkan。
- 本转换版是**白模 + 烘焙光照**的近似还原：原关卡材质图/材质图节点未做完整解析，地形与道具以层权重混色、纯色白模呈现；烛台等特殊网格用近似几何替代。
- 仅保留**可见**地形（原工程里有 7 个被隐藏到 -1km 的旧地形副本，已排除）。
